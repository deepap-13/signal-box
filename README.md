# Signal Box

A railway-dispatcher themed decision game teaching the four NGO reform pathways for public education systems, drawn from Mantra4Change's IIM conference paper *"Reimagining the Role of Non-Governmental Organisations (NGOs) in Building an Atmanirbhar Public Education System."*

Play: https://deepap-13.github.io/signal-box/

Route 6 scenario "tickets" to one of four moves, then unlock the Track Guide — the full framework with real case studies (Odisha Rising Foundation, Sanjhi Sikhiya, Mantra4Change/Bihar PBL, Punjab Education Collective / Shikshagraha).

No backend, no accounts, no data collection.
